# Auto News Studio

Auto News Studio 是一个面向公众号内容运营的 AI 新闻选题与草稿工作台。

它的核心目标不是单纯“抓新闻”，而是把每天的信息流整理成一条真正可落地的内容链路：发现信息、筛出热点、补齐背景、整理素材、写成文章、送入公众号草稿箱，再回看后续结果。

当前版本：`0.2.11`

## 它适合谁

- 每天需要追科技、AI、互联网行业动态的公众号运营者
- 需要把“看新闻”变成“做选题”的个人创作者和小团队
- 想让 AI 参与写作，但又不希望内容脱离真实素材和真实发布链路的人

## 当前版本能做什么

### 1. 把分散信息收回到一个工作台

- 聚合多个常见科技与热点来源
- 自动把重复报道收敛成同一事件
- 给事件做热度判断和优先级排序
- 区分“刚出现”“值得观察”“正在升温”“已经转冷”的不同状态

这一步解决的是信息太杂、太碎、太重复的问题。

### 2. 从“知道发生了什么”走到“知道为什么值得写”

- 对重点事件补充上下文和背景信息
- 整理关键事实、时间线、引文和来源
- 形成可直接用于写稿的本地素材记录
- 支持对同一主题继续追踪，不是只看一眼就结束

这一步解决的是“新闻看到了，但还不能直接写”的问题。

### 3. 让写作不只是一段 AI 输出

- 支持把素材整理成公众号长文
- 强化标题、摘要、导语、结构、小标题和结尾规范
- 对事实、数字、日期、引文做更严格的约束
- 要求 AI 写作先出初稿，再复审，再决定是否保存

这一步的重点不是“写得快”，而是让成稿更像一篇能发的文章，而不是拼接摘要。

### 4. 直接接到公众号草稿箱

- 支持把文章送入微信公众号草稿箱
- 支持查看草稿同步结果
- 支持回看公众号发表记录
- 尽量避免重复上传同一篇内容

这一步把“写完”接到了“可发布”。

### 5. 让日常运行更稳定

- 可以看信息源是否健康
- 可以查看运行状态与操作日志
- 可以按不同自动化强度运行传统模式
- 重复启动时优先复用已有控制台页，减少浏览器标签页堆积

## 两种主要使用方式

### 传统模式

适合把它当成一个日常内容后台来用。

你可以在界面里看当天信息流、热点事件、深挖结果、简报/文章记录、微信草稿箱映射和系统状态。传统模式更像一个持续运行的编辑部工作台。

### Agent 模式

适合让外部 AI 直接参与当天工作。

在这种方式下，AI 不只是聊天助手，而是按项目既有流程来推进选题、深挖、写稿和上传。项目负责真实数据和真实发布链路，AI 负责判断、整理和写作。

### Agent HTML 模式

这是当前版本里额外提供的一条定向采集能力。

它适合品牌官网、新闻页、博客页这类没有稳定订阅源、但页面结构相对固定的内容场景。它更像“补源能力”，不是替代主工作台。

## 一天的典型工作方式

一个比较自然的日常节奏通常是这样：

1. 先看今天有哪些新事件冒出来
2. 从中挑出真正值得写的主题
3. 补齐背景、事实和时间线
4. 形成本地素材记录
5. 写成公众号文章
6. 推到微信草稿箱
7. 后续继续看草稿和发表结果

如果你用的是 Agent 模式，这套动作也可以由 AI 协助推进，但最终仍然落回同一套项目记录里。

## 这个项目当前最适合处理的内容

- AI 产品与模型动态
- 科技公司动作与行业变化
- 开发者圈热点
- 平台政策、基础设施、安全事件
- 品牌官方更新、博客、发布说明

如果你的内容方向本来就偏科技、AI、互联网，这套工作流会更顺手。

## 快速开始

### 环境要求

- Python 3.11+
- Node.js 20+
- 可正常使用的 Chromium / Edge 浏览器环境

### 安装

首次安装建议直接运行：

```bash
install.bat
```

### 启动

```bash
start.bat
```

启动后，项目会打开本地控制台页面。重复启动时会优先唤醒已有页面，而不是一直新开标签页。

### 停止

```bash
stop.bat
```

### 自检

```bash
doctor.bat
```

## 初次使用时建议先完成这几件事

### 1. 配置模型服务

项目支持接入常见的大模型服务商，用于摘要、深挖和写作辅助。你只需要在设置里填写自己准备使用的服务配置即可。

### 2. 准备公众号登录态

如果你要把内容直接送进微信草稿箱，需要先让项目能够复用你的公众号后台登录状态。

### 3. 跑一遍最小闭环

推荐第一次不要追求全自动，而是先完整走一遍：

1. 看热点
2. 选一个事件
3. 做深挖
4. 生成素材记录
5. 写一篇文章
6. 同步到草稿箱

这样最容易确认整条链路已经打通。

## 你会在界面里看到什么

- 总览：今天整体情况、待处理内容、运行状态
- 实时流：原始信息输入
- 热点簇：合并后的事件池
- 预警台：正在升温或值得盯的主题
- 深挖池：已经进入继续处理阶段的事件
- 简报 / 文章：本地素材和成稿记录
- 微信草稿箱：本地记录与草稿箱的对应情况
- 设置：模型、渠道和系统相关配置

## 当前版本的产品定位

Auto News Studio 现在更像一个“内容工作台”，不是一个只会抓 RSS 的阅读器，也不是一个只会生成文字的写稿工具。

它强调的是三件事：

- 信息要先收束，不要直接在噪音里写
- 写作要基于素材，不要脱离事实乱发挥
- 发布要接到真实平台，不要停在一篇本地文档
