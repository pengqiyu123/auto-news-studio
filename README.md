# Auto News Studio

独立运营后台，用于控制自动化新闻助手的采集、生成、公众号草稿、预览与发送流程。

## 目录结构

```text
auto-news-studio/
├── backend/      # FastAPI 后端
├── frontend/     # React + Vite 运营后台
└── references/   # 高星参考项目
```

## 当前实现

- 发布模式管理
- 仪表盘概览
- 稿件工作台
- 任务中心
- 微信公众号渠道配置
- 日志面板

## 下一步

- 接入真实新闻采集管道
- 接入公众号草稿 API
- 增加预览与审核流
- 增加浏览器自动化兜底
