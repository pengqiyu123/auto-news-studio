# 0.2.6 更新说明

## 本次重点
- 修正 Agent 长文工作流边界：先生成本地素材记录，再由 AI 写长文并通过 `POST /api/admin/agent/articles` 上传。
- 增加 Agent 与传统调度器互斥保护，避免运行中的 scheduler 与 Agent 同时写入微信草稿箱。
- 修复 Agent 长文与传统简报混写的问题，长文现在会以独立 `article` 记录保存到共享 `briefs`。
- 补齐本地测试、手工回归、发版流程文档，明确后端改动后必须重启再做 API 验证。
- 优化前端提示：后台自动检查微信草稿箱 / 发表记录时，会通过右下角气泡提示当前进展。

## 兼容性
- 版本号已更新为 `0.2.6`。
- GitHub Releases 需要同步发布 `v0.2.6`，旧版本才会识别到更新。

## 备注
- 传统模式继续保留三档自动化。
- Agent 与 Studio 继续共用 `data/state.json`，不引入第二套业务数据库。
- 分发包继续包含项目 `.venv`，保持离线可安装。
