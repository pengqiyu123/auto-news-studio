## 安装与启动

### Q：双击 install.bat 闪退或报错

**A：** 按以下步骤排查：

1. 确认 Python 3.11+ 已安装：打开命令行输入 `python --version`
2. 确认 Node.js 20+ 已安装：输入 `node --version`
3. 如果两个都有但 install.bat 仍报错，手动执行：
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r backend\requirements.txt
   cd frontend
   npm install
   npm run build
   ```

### Q：start.bat 启动后浏览器没有打开

**A：** 检查以下几点：

1. 是否有其他程序占用了 8000 端口：打开 `http://127.0.0.1:8000` 看是否可以访问
2. 查看 `runtime\logs\backend.err.log` 末尾是否有错误信息
3. 运行 `stop.bat` 后重新 `start.bat`

### Q：启动报错"Port 8000 is occupied"

**A：** 运行 `stop.bat`，或手动关闭占用 8000 端口的进程：
```bash
stop.bat
start.bat
```

### Q：doctor.bat 报错

**A：** doctor.bat 会检查环境完整性。常见问题：
- `.venv` 不存在 → 先运行 `install.bat`
- `frontend\dist` 不存在 → 运行 `cd frontend && npm run build`

## 模型配置

### Q：支持哪些大模型？

**A：** 支持 8 家提供商：

| 提供商 | 推荐场景 |
|--------|---------|
| DeepSeek | 性价比高，中文能力好 |
| OpenRouter | 一个 Key 用多个模型 |
| 智谱 GLM | 国产模型，中文优秀 |
| 豆包（火山引擎）| 国产模型 |
| SiliconFlow | 有免费额度 |
| 通义千问 | 阿里云用户 |
| OpenAI | GPT 系列 |
| NVIDIA NIM | 有 NVIDIA 账号可用 |

### Q：必须配 API Key 吗？

**A：**
- **传统模式**：不配也可以用，但只能做采集和评分，不能自动写稿。手动模式的"生成今日速递"使用规则模板，不依赖 LLM。
- **Agent 模式**：必须配置至少一个 LLM API Key。
- **建议**：至少配一个，推荐 DeepSeek 或 SiliconFlow（成本低）。

### Q：API Key 存在哪里？安全吗？

**A：** 存在你本地的 `data\state.json` 文件中，不会上传到任何服务器。不要在截图或录屏中暴露你的 API Key。

## 数据与存储

### Q：数据存在哪里？

**A：** 默认存在本地 `data\state.json` 文件中。如果配置了 PostgreSQL，则同时写入数据库。

### Q：需要装 PostgreSQL 吗？

**A：** 不是必须的。默认使用 JSON 文件存储，适合轻量使用。如果需要长期保存历史数据和分析趋势，建议开启 PostgreSQL：
```bash
docker compose -f docker-compose.postgres.yml up -d
```
详见 [docs/POSTGRES_SETUP.md](./POSTGRES_SETUP.md)。

### Q：JSON 模式的 480 条上限是什么意思？

**A：** JSON 模式下 `raw_items`（原始采集数据）最多保留 480 条，超出后旧数据会被清理。这只影响 JSON 文件，PostgreSQL 中会保留全量数据。事件、简报等重要数据不受此限制。

## 微信公众号

### Q：如何让工具能操作我的公众号？

**A：**
1. 在浏览器中登录微信公众号后台（mp.weixin.qq.com）
2. 保持登录状态，不要退出
3. 工具会复用你的浏览器登录态来操作草稿箱

### Q：工具会自动发布文章吗？

**A：** 普通产品流程只会同步到公众号草稿箱。Agent/调试流程可以继续帮你做发表前检查，例如 AI 封面、原创声明、赞赏、合集、创作来源，并点击到“微信验证”二维码处停止。

二维码出现后仍然需要人工扫码或管理员确认。系统不会把“到达二维码”当成“已发布成功”。

### Q：为什么点击编辑后截图还是草稿箱？

**A：** 微信公众号后台常会在新标签页打开编辑器，旧草稿箱标签页还留着。草稿箱 URL 里通常有 `action=list_card`，编辑页 URL 应包含 `action=edit`。如果截图仍是草稿箱，请关闭旧草稿箱标签页，保留编辑页后再继续。

### Q：为什么打开目标草稿后进了预览，不是编辑页？

**A：** 草稿卡片里的标题、封面或第一个链接可能是预览入口，不能用它们作为编辑入口。正确路径是进入草稿箱后，定位目标草稿卡片，再点击卡片操作区的“编辑”按钮。判断是否成功只看最终 URL：包含 `action=edit` 才是编辑页；包含 `action=list_card` 仍是草稿箱，普通 `/s/` 链接通常是预览页。

2026-06-21 已实测通过：目标草稿被识别后，自动化点击操作区“编辑”按钮，成功进入 `action=edit` 编辑页。该步骤只代表编辑页打开成功，不代表文章已经发表。

### Q：AI 封面流程卡住怎么办？

**A：** 先确认当前在编辑页，然后按顺序检查：

1. 是否已经点击“拖拽或选择封面”
2. 是否能看到“AI 配图”
3. 提示词是否已填入 `ai-image-prompt`
4. 是否出现“已为你生成图片”
5. 是否点击了“使用”和最后的“确认”

如果生成中长时间没有完成，可以重新打开封面弹窗再试一次。

### Q：点击发表后为什么没有出现二维码？

**A：** 先看截图当前停在哪一层。2026-06-21 的真实问题是二次确认弹窗还在，代码却开始等待二维码。正确路径是：

1. 点击编辑页底部第一层“发表”
2. 点击 popover/dialog 确认层里的绿色“发表”
3. 如出现“继续发表”，再点击“继续发表”
4. 等待“微信验证”二维码

二次确认不能使用全局 `button:has-text('发表')`，它可能又点到底部原始发表按钮。AI Agent 排障时请看 [微信 Agent 发表前确认 Runbook](./WECHAT_AGENT_PUBLISH_RUNBOOK.md)。

### Q：Trae 或其他 AI 不会操作这条链路怎么办？

**A：** 让它先读以下文件：

1. `AGENTS.md`
2. `AGENT.md`
3. `docs/AGENT_DAILY_WORKFLOW_RUNBOOK.md`
4. `docs/WECHAT_AGENT_PUBLISH_RUNBOOK.md`
5. `.trae/rules/project-agent-workflow.md`

执行时必须一步一验：健康检查、采集、深挖、写作、保存、上传草稿、打开草稿到 `action=edit`、补齐设置、点击到二维码。失败后先收集 session、最新截图和日志，不要继续盲点。

### Q：`agent/articles` 保存成功但微信草稿上传超时怎么办？

**A：** 不要删除本地文章，也不要重新生成一篇。推荐路径是：

1. `POST /api/admin/agent/articles` 保存时使用 `publish_to_wechat_draft=false`
2. 记录返回的 `item.id`，也就是后续上传用的 `brief_id`
3. 用 `POST /api/admin/briefs/{brief_id}/wechat-draft?triggered_by=agent` 单独上传
4. 如果上传失败，先恢复微信浏览器，再用同一个 `brief_id` 重试

`sidecar_health=offline` 不能单独判定为根因。更应该同时看 `logged_in`、`manager_alive`、`last_error`、`last_reset_reason`、`current_page` 和真实浏览器检查结果。完整顺序见 [Agent 每日工作流 Runbook](./AGENT_DAILY_WORKFLOW_RUNBOOK.md)。

### Q：微信公众号改版了，工具不能用了怎么办？

**A：** 发布功能基于浏览器自动化（Playwright），平台改版可能导致操作失效。建议有 Claude Code 或 Codex 的用户自行修复，AI 可以分析新的页面结构并更新自动化脚本。

### Q：同步到草稿箱后在哪里看？

**A：** 两种方式：
1. 在 Auto News Studio 的 **微信草稿箱** 页面查看同步状态
2. 直接在微信公众号后台的"草稿箱"中查看

## 抖音

### Q：抖音发布是怎么工作的？

**A：** 在 Agent 模式下，AI 会自动将每日新闻制作成 5 条科技要闻的短视频文案，并通过浏览器自动化填入抖音创作平台的编辑器。需要在浏览器中预先登录抖音创作服务平台。

### Q：能自动发视频吗？

**A：** 目前只支持填入文字内容（标题、摘要、正文），不包含自动上传视频素材。你需要自己准备视频画面。

## Agent 模式

### Q：什么是 Agent 模式？

**A：** Agent 模式是让外部 AI（如 Claude Code、Codex）直接操作项目的工作方式。AI 会读取项目中的 `AGENT.md` 文件，了解所有可用 API，然后自主决定采集什么、写什么、怎么写、发到哪里。

### Q：必须用 Agent 模式吗？

**A：** 不是必须的。传统模式（手动/计划）完全可以独立使用。Agent 模式的优势在于 AI 能做更灵活的判断，比如根据当天素材决定写长文还是短讯。

### Q：我没有 Claude Code 或 Codex，能用 Agent 模式吗？

**A：** Agent 模式需要外部 AI 工具来驱动。如果你没有这些工具，使用传统模式即可。

## 运行与性能

### Q：需要一直开着电脑吗？

**A：**
- 手动模式：不需要，用的时候打开就行
- 计划模式：如果设置了定时批量上传，需要在设定时间前后保持运行
- Agent 模式：AI 操作时需要保持运行

### Q：会占用多少资源？

**A：**
- 后端 Python 进程：约 100-200MB 内存
- 浏览器自动化（微信/抖音操作时）：额外 200-400MB
- 普通采集和评分：几乎不占资源

### Q：可以部署到服务器上吗？

**A：** 项目设计为本地单机使用。如果要部署到服务器，需要修改 CORS 配置和端口绑定。目前没有提供服务器部署方案。

## 故障排除

### Q：采集没有数据

**A：** 检查以下几点：
1. 确认网络连接正常
2. 在 **信息源健康** 页面查看各数据源的状态
3. 部分数据源可能被墙，需要代理

### Q：生成的文章质量不好

**A：**
1. 尝试更换 LLM 提供商或模型
2. 确认深挖（背景调查）已完成，素材越丰富文章越好
3. 使用 Agent 模式，AI 会做更精细的写作判断

### Q：微信同步失败

**A：**
1. 确认公众号后台仍在登录状态
2. 在 **设置** 页面查看微信连接状态
3. 查看 `runtime\logs\` 目录下的日志了解具体错误
4. 如果要打开已有草稿，先刷新 **微信草稿箱**，确认目标草稿仍存在
5. 尝试在浏览器中重新登录公众号后台
