# 0.2.10 更新说明

本次版本聚焦抖音文章发布链路优化，核心目标是把“能填进去”升级成“按抖音规则稳定填进去”。

## 主要更新

### 1. 抖音内容链路正式拆分为独立轨道

- 文章记录新增抖音专用字段：`douyin_title`、`douyin_summary`、`douyin_markdown`、`douyin_prompt_package_markdown`。
- 抖音填充不再直接复用公众号稿件字段，而是优先使用抖音专用标题、摘要和正文。
- 历史旧记录即使没有完整抖音字段，也能在填充前按当前规则自动兜底生成。

### 2. 抖音摘要规则重写，解决 30 字内残句问题

- 抖音摘要上限继续保持 `30` 字。
- 新规则优先保留完整信息单元，而不是简单截断字符。
- 对官方长表述做定向压缩，例如把 `国行 Nintendo Switch 网络相关运营服务正式停止` 压缩成更适合抖音摘要位的短句。
- 新增“低质量旧摘要重算”机制，像 `...正式` 这类半句话会在填充前自动替换。

### 3. 抖音正文生成更贴近移动端发布场景

- 抖音正文构建不再默认沿用公众号长文形态。
- 标题、摘要、导语和正文拆分逻辑统一接入抖音链路。
- 历史回填时会优先清理过长、过重、过像公众号导语的首段结构。

### 4. 发布侧与生成侧规则统一

- `backend/app/publishers.py` 的抖音摘要兜底规则已改为复用统一摘要生成函数，避免“本地看着对，页面填进去又变样”。
- 浏览器填充前会再次检查抖音摘要质量，确保页面实际写入的是当前合格结果。
