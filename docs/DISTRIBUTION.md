# Auto News Studio Windows 分发说明

## 适用范围

- Windows 单用户、本机运行
- 每位用户各自维护自己的配置和公众号登录态
- 不共享微信浏览器 profile，不共享登录态

## 安装

1. 解压发布包
2. 运行 `install.bat`
3. 运行 `start.bat`
4. 打开 `http://127.0.0.1:8000`

## 分发包内容

Windows 分发包默认包含：

- 后端代码
- 前端 `dist`
- 项目 `.venv`
- 启动 / 停止 / 自检脚本

这样做的目的是让离线环境也能直接运行，不需要先重新安装依赖。

## 首次配置

1. 前往 `设置 > AI 模型` 填入至少一个可用 API Key
2. 前往 `设置 > 微信浏览器` 保存浏览器与 profile 路径
3. 打开公众号后台并完成登录检查
4. 前往 `设置 > 系统偏好` 查看自检结果

## 备份与恢复

- `导出配置`：只导出用户配置
- `导出备份`：导出配置、运行数据和日志摘要
- `导入备份`：恢复后仍需重新登录公众号后台

## 常见问题

- `frontend/dist` 缺失：当前发布包不完整
- 微信未登录：前往设置页执行浏览器登录检查
- AI 未配置：前往设置页填入 API Key 并保存

## 打包说明

- 分发包由 `scripts/build_release.ps1` 生成
- 该脚本会把 `.venv` 一并打入包内，保持 offline-ready
- 如果本机没有 `.venv`，则分发包需要在目标机器上联网安装依赖
