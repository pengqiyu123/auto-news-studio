# Quick Start — 从安装到发布第一篇文章

本文档帮助你在 30 分钟内完成安装、配置、采集、写作和发布的完整闭环。

---

## 前提条件

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| Python | 3.11 或 3.12 |
| Node.js | 20+ |
| 浏览器 | Chromium 或 Edge |
| 磁盘空间 | 约 2 GB（含依赖） |

**可选但推荐：**
- Claude Code 或 Codex 订阅 — 用于 Agent 模式（AI 自主选题、写稿、发布）
- 微信公众号 — 用于自动同步草稿箱
- 至少一个 LLM API Key — 用于内容生成

---

## 第一步：安装

### 方式 A：一键安装（推荐）

双击项目根目录的 `install.bat`，它会自动完成：
- 创建 Python 虚拟环境
- 安装后端依赖
- 安装前端依赖并构建

### 方式 B：手动安装

```bash
# 后端
python -m venv .venv
.venv\Scripts\activate
pip install -r backend\requirements.txt

# 前端
cd frontend
npm install
npm run build
cd ..
```

---

## 第二步：启动

```bash
start.bat
```

启动后浏览器会自动打开 `http://127.0.0.1:8000`。

如果端口 8000 已被占用，脚本会自动检测并提示。运行 `stop.bat` 可以停止服务。

---

## 第三步：配置模型服务

打开界面后，进入 **设置** 页面，找到"模型配置"区域。

你需要至少配置一个 LLM 服务才能使用写作功能。项目支持以下提供商：

| 提供商 | 获取 API Key |
|--------|-------------|
| DeepSeek | platform.deepseek.com |
| OpenRouter | openrouter.ai |
| 智谱 GLM | open.bigmodel.cn |
| 豆包（火山引擎）| volcengine.com |
| SiliconFlow | siliconflow.cn |
| 通义千问 | dashscope.aliyuncs.com |
| OpenAI | platform.openai.com |
| NVIDIA NIM | build.nvidia.com |

在设置页面填入你选择的提供商的 API Key，选择模型，保存即可。

---

## 第四步：采集信息

进入 **总览** 页面，点击"启动"按钮开始传统模式。

系统会自动从预设的 20+ RSS 源、30+ YouTube 频道和 8 个热榜源采集信息。首次采集大约需要 1-2 分钟。

采集完成后，你可以在 **实时流** 页面看到原始信息，在 **热点簇** 页面看到合并后的事件。

---

## 第五步：选择操作模式

### 手动模式（推荐新手）

手动模式下，你需要逐步触发每个阶段：
1. 在 **热点簇** 页面查看今天的事件
2. 选择感兴趣的事件，点击"深挖"
3. 深挖完成后，点击"生成今日速递"
4. 在 **简报** 页面查看生成的文章

### 计划模式

计划模式下，系统按你设定的交付设置自动运行。在 **总览** 页面的设置面板中选择"计划模式"，然后选择交付深度：

| 交付设置 | 效果 |
|---------|------|
| 不生成简报 | 只做采集和评分 |
| 仅生成本地简报 | 自动生成今日速递，不上传 |
| 立即上传微信 | 生成后自动上传到公众号草稿箱 |
| 定时批量上传 | 在设定时间批量上传 |

### Agent 模式（推荐进阶用户）

如果你有 Claude Code 或 Codex，可以让 AI 自主完成从选题到发布的全流程：

1. 确保已配置 LLM 服务
2. 让 AI 读取项目根目录的 `AGENT.md`
3. AI 会自动调用 API 完成采集、深挖、写稿和发布

Agent 模式的优势：
- AI 可以根据当天素材自动决定写长文还是短讯合集
- AI 可以判断哪些事件值得深挖、哪些不值得
- 支持同时发布到微信公众号和抖音

## 第六步：发布到微信公众号

### 前置条件

1. 在浏览器中登录微信公众号后台（mp.weixin.qq.com）
2. 在 Auto News Studio 的 **设置** 页面确认微信配置已就绪
3. 第一次跑发布链路时，建议先用已有草稿测试，不要直接新建并发表

### 操作方式

**手动上传**：在 **简报** 页面找到已生成的文章，点击"同步到微信草稿箱"。

**自动上传**：使用计划模式并选择"立即上传微信"或"定时批量上传"，系统会通过浏览器自动化将文章送入草稿箱。

**发表前检查**：在 Agent 模式下，可以让 AI 打开一个已有微信草稿，补齐封面和发布设置，然后点击到微信验证二维码处停止。

当前微信链路分为两层：

1. **同步草稿箱**：把本地文章上传到微信公众号草稿箱，适合日常生成和人工复核。
2. **发表前确认**：打开已有草稿，执行 AI 封面、原创声明、赞赏、合集、创作来源等设置，再点击发表链路直到出现微信验证二维码。

发表前确认的停止条件是检测到“微信验证”二维码。系统会截图并停下，提醒你扫码或联系管理员验证；这时还不能把文章视为已经发布成功。

建议按这个顺序验证：

1. 点击 **微信草稿箱** 页面刷新，确认目标草稿存在。
2. 打开目标草稿的编辑页，确认 URL 包含 `action=edit`。
3. 执行封面流程：点击“拖拽或选择封面” -> “AI 配图” -> 填写 50 字以内提示词 -> 发送 -> 等到“已为你生成图片” -> “使用” -> “确认”。
4. 执行发布设置：原创声明、赞赏、合集和创作来源。
5. 点击“发表”，在二次确认和“继续发表”后等待“微信验证”二维码。
6. 截图后停止自动化，人工扫码完成最终确认。

注意事项：

- 草稿箱页面 URL 通常包含 `action=list_card`，它不是编辑页。
- 编辑页 URL 应包含 `action=edit`。如果浏览器同时保留草稿箱和编辑页两个标签页，应关闭草稿箱标签页，保留编辑页再继续。
- 二维码出现后不要继续自动点击；扫码结果以微信公众号后台实际状态为准。

发布后，你可以在 **微信草稿箱** 和 **发布历史** 页面查看同步状态和发布效果。

---

## 第七步：发布到抖音

在 Agent 模式下，AI 可以自动将每日新闻制作成抖音短视频文案并填入创作平台：

1. 在浏览器中登录抖音创作服务平台
2. 让 AI 执行带 `publish_to_douyin_article=true` 的发布流程
3. AI 会自动生成 5 条科技要闻的短视频文案并填入编辑器

## 使用 PostgreSQL（可选）

默认使用 JSON 文件存储，适合轻量使用。如果你需要长期数据分析和历史回看：

1. 启动 PostgreSQL：
   ```bash
   docker compose -f docker-compose.postgres.yml up -d
   ```

2. 设置环境变量：
   ```
   STATE_BACKEND=dual_write
   DATABASE_URL=postgresql+psycopg://postgres:postgres@127.0.0.1:5432/auto_news_studio
   ```

3. 初始化数据库：
   ```bash
   .venv\Scripts\python.exe scripts\init_postgres.py
   ```

详细配置参考 [docs/POSTGRES_SETUP.md](./POSTGRES_SETUP.md)。
