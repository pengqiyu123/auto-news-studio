## 正文

### 这是什么

Auto News Studio 是一个跑在你自己电脑上的 AI 新闻选题与发布工作台。

它做的事情很简单：每天自动采集科技新闻 → AI 筛选热点 → 自动写稿 → 一键同步到公众号草稿箱和抖音创作平台。

不是又一个 RSS 阅读器，也不是又一个 AI 写作工具。它把「发现信息 → 筛选题 → 补背景 → 写文章 → 发到平台」这件事串成了一条完整的链路。

### 能做什么

**信息采集**
- 自动聚合 20+ 科技 RSS 源（TechCrunch、The Verge、36氪、机器之心等）
- 监控 30+ YouTube 频道（OpenAI、Google AI、各大手机厂商官方频道）
- 抓取 Reddit、Hacker News、GitHub Trending 等社区热榜
- 自动去重、聚类，把多家报道的同一件事合并

**AI 写稿**
- 支持 8 家大模型：DeepSeek、OpenAI、智谱GLM、豆包、SiliconFlow、通义千问、OpenRouter、NVIDIA
- 两种写作模式：
  - 传统模式：规则驱动，自动生成每日科技速递合集
  - Agent 模式：AI 自主判断写长文还是短讯，全自动完成
- 写作基于真实素材，不是让 AI 凭空编

**一键发布**
- 自动同步到微信公众号草稿箱（不会自动点发布，你确认后才发）
- 支持抖音创作平台（5 条要闻短视频文案）
- 支持定时批量上传

### 适合什么人

- 科技/AI 领域公众号运营者
- 需要 AI 辅助选题和写稿的个人创作者
- **需要你有一定的技术基础**：能装 Python 和 Node.js，能配 API Key
- **推荐有 Claude Code 或 Codex**：遇到问题可以让 AI 帮你排查和修复

### 不适合什么人

- 不想碰命令行和技术配置的人
- 内容方向不是科技/AI/互联网的（数据源偏这些领域）
- 期望完全自动赚钱的（这只是工具，内容质量还需要你把关）

### 常见问题

**Q：我需要什么配置的电脑？**
普通笔记本就行，4GB 以上内存。主要消耗在网络请求和浏览器自动化上。

**Q：需要联网吗？**
需要。采集信息和调用 LLM 都需要网络。

**Q：我的数据安全吗？**
所有数据存在你本地电脑上，不会上传到任何第三方服务器。API Key 只存在你本地的配置文件中。

**Q：微信公众号改版了怎么办？**
发布功能基于浏览器自动化，平台改版可能导致失效。建议有 Claude Code 或 Codex 的用户购买，遇到改版可以借助 AI 工具自行修复。

**Q：支持 Mac/Linux 吗？**
目前主要支持 Windows。后端和前端本身是跨平台的，但启动脚本只有 Windows 版本。
