# 微信总账与抖音接入说明（v0.2.8）

## 本次目标

`v0.2.8` 主要完成两件事：

1. 把“简报”重新定义为唯一的本地总账
2. 新增抖音创作者中心文章发布页的基础自动化能力

## 微信侧调整

### 简报页

- 简报不再以 `prepared / synced / failed` 作为主展示逻辑
- 现在统一展示为三种总账主状态：
  - `仅本地`
  - `已同步草稿箱`
  - `已同步发表记录`
- 若存在异常，再叠加：
  - `待确认`
  - `草稿箱检查失败`
  - `发表记录检查失败`
  - `草稿已丢失`

### 发表记录页

- 继续保持只读
- 继续直接展示公众号后台真实发表记录
- 不承担本地管理职责

### 微信草稿箱页

- 页面职责调整为对账工作台
- 固定视图：
  - `微信端`
  - `本地记录`
  - `待确认`
- “本地记录”直接复用 `briefs` 总账，不再新建第二份本地数据库

## 抖音侧调整

新增抖音创作者中心基础链路：

- 独立浏览器 session
- 打开抖音创作者中心
- 打开文章发布页
- 探测文章发布页结构
- 自动填充：
  - 标题
  - 摘要
  - 正文
- 自动点击 `AI 配图`

当前版本先完成“打开、探测、填充”的可靠链路，不在无页面校准证据时自动点击最终发布按钮。

## 后端实现口径

微信本地总账状态由后端实时投影，不写死入库：

- `record_status`
- `record_exception`
- `draft_remote_updated_at`
- `publish_record_published_at`
- `record_counts`

匹配规则统一复用同一套逻辑：

1. `wechat_remote_appmsg_id`
2. 远端 URL
3. 标题归一化后的前缀 / 包含匹配
